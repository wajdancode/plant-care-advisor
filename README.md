# 🌿 Plant Care Advisor
AI-powered plant care guide — built with Streamlit + **Gemini 3.5 Flash**.
Upload a plant photo OR type its name → get complete care instructions instantly.

## ✨ Features
- 📸 Identify plant from image
- ✍️ Search by plant name
- 💧 Watering schedule & tips
- ☀️ Light, temperature & humidity guide
- 🪴 Soil & fertilizer recommendations
- ⚠️ Common problems + fixes

## 🛠️ Tech Stack
- Frontend/UI: Streamlit
- AI Model: **Google Gemini 3.5 Flash** ✅ (latest recommended model)
- Image Handling: Pillow

## 🔑 Get Your API Key
1. Go to https://aistudio.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key" → Copy your key
4. Keep it safe — never share publicly!
